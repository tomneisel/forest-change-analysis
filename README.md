# Forest Change Analysis

Analysis of forest change in the Harz region using Sentinel-2 satellite imagery
and machine learning.

## Overview

This project investigates changes in forest cover in the Harz region between
2018 and 2026 using Sentinel-2 satellite imagery.

The main goal is to classify the study area into forest and non-forest areas
and analyse changes in forest cover over time.

## Workflow

1. Sentinel-2 image acquisition
2. Image preprocessing
3. NDVI calculation
4. Training data creation
5. Forest / non-forest classification
6. Forest change detection
7. Forest area calculation
8. Visualisation of results

## Methods

- Sentinel-2 Level-2A
- NDVI
- Random Forest classification
- Forest / Non-Forest classification
- Change detection

## Study Area

Harz region, Germany.

## Years

- 2018
- 2023
- 2026
